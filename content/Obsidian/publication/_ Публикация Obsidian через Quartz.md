# Публикация Obsidian через Quartz

> Quartz — бесплатный инструмент для превращения Obsidian Vault в публичный сайт с сохранением графа связей.

## Что получим на выходе

- Статический сайт с навигацией
- Интерактивный граф связей
- Поддержка `[[wikilinks]]` из Obsidian
- Backlinks на каждой странице
- Поиск по заметкам
- Бесплатный хостинг на GitHub Pages
