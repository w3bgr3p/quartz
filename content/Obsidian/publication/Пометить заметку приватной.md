В [[Настройка Quartz]] `quartz.config.ts`, вот точное место:

```typescript
const config: QuartzConfig = {
  configuration: {
    pageTitle: "...",
    // ...
    ignorePatterns: ["private", "templates", ".obsidian"], // ← сюда
    // ...
  },
}
```

## Как помечать заметки приватными

**Вариант А — папка** (проще всего)

Положи заметки в папку `private/` внутри vault — вся папка игнорируется.

```
vault/
├── private/
│   └── моя секретная заметка.md  ← не публикуется
└── публичная заметка.md
```

**Вариант Б — frontmatter** (для отдельных файлов)

```yaml
---
draft: true
---
```

Это встроенный механизм Quartz — файл с `draft: true` не попадёт на сайт. Добавлять в `ignorePatterns` ничего не нужно, работает из коробки.
