## Требования

| Инструмент | Версия | Проверка |
|---|---|---|
| [Node.js](https://nodejs.org/) | >= 18.14 | `node -v` |
| [Git](https://git-scm.com/) | любая | `git --version` |
| npm | >= 9.3.3 | `npm -v` |

## Установка Node.js

### macOS
```bash
brew install node
```

### Windows
Скачать установщик с [nodejs.org](https://nodejs.org/) → выбрать LTS версию.

### Linux (Ubuntu/Debian)
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
```

## Клонирование репозитория Quartz

```bash
git clone https://github.com/jackyzha0/quartz.git
cd quartz
npm install
```

> [!NOTE]
> Папка `quartz/` — это не твой vault, а движок сайта. Vault будет подключён отдельно на [[Настройка Quartz|следующем шаге]].

## Проверка установки

```bash
npx quartz --help
```

Если выводится справка — установка прошла успешно.
